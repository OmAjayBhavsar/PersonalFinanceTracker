# Personal Finance Tracker

A simple web-based personal finance tracker for recording income and expenses and monitoring the resulting balance.

The project was built using HTML, CSS, and JavaScript as a personal project to practice frontend development, DOM manipulation, and browser-based data persistence.

## Features

- Add income and expense transactions
- Display transaction history
- Delete individual transactions
- Automatically calculate total balance
- Calculate total income and expenses
- Store transaction data locally in the browser using `localStorage`
- Preserve transactions after page reloads

## Technologies

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Browser Local Storage

## How It Works

Each transaction contains a description and an amount.

- Positive amounts are treated as income
- Negative amounts are treated as expenses
- JavaScript automatically recalculates the balance, total income, and total expenses
- Transactions are stored in the browser using `localStorage`
